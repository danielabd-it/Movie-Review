# Movie Review Website

A full-stack movie review website built with **Node.js, Express, MongoDB Atlas, and EJS**. The application allows users to create and manage personal movie reviews, making it useful as a private movie journal or personal movie-tracking platform.

## Overview

<img width="1908" height="891" alt="image" src="https://github.com/user-attachments/assets/4240085f-4c41-412f-ac33-27d73324a996" />

This project was developed to demonstrate full-stack web development using a Node.js and Express backend with a MongoDB database and EJS for server-side rendered pages.

Users can use the application to keep track of movies they have watched and create personal reviews that can be managed through the website.

The project focuses on building a complete web application that connects the frontend, backend, and database into a single system.

## Features

* Create personal movie reviews
* Write and manage movie journal entries
* Record personal movie ratings and opinions
* View previously created movie reviews
* Store application data using MongoDB Atlas
* Server-side rendered pages using EJS
* Backend routing and request handling with Express
* CRUD-based database operations
* Responsive web interface
